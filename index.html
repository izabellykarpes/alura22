Mercado Financeiro

Visualização simples e interativa usando p5.js

Resumo

Este demo mostra um gráfico de preços com interação mínima — ideal como página inicial de projeto sobre mercado financeiro.

Controles

  • Passe o mouse sobre o gráfico para ver tooltip.
  • Redimensione a janela para tornar o canvas responsivo.

Sobre

O código está otimizado para trabalhar dentro do ciclo p5 (preload / setup / draw). Os dados aqui são de exemplo — substitua pela sua fonte (API, CSV, etc.).
